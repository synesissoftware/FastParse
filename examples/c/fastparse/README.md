# example.c.fastparse <!-- omit in toc -->


## Purpose

Prints the **FastParse** version string from `fastparse_getVersionString()`.


## Build

Built when `BUILD_EXAMPLES` is enabled (the default).


## Run

```sh
${SIS_CMAKE_BUILD_DIR:-./_build}/examples/c/fastparse/example.c.fastparse
```


## Expected output

```
0.1.0-alpha1
```
